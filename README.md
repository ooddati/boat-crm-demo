# BOAT Education Group Website + CRM Portal Demo

A responsive, static UI/UX prototype built with HTML and CSS only. It contains a public marketing website plus Student, Agent, and Super Admin portal views.

## Open the demo

1. Extract the project folder if you received it as a ZIP file.
2. Open `index.html` in any modern browser.
3. Select **Portal Login** to access the Student, Agent, and Admin demo entry points.

No server, installation, build step, JavaScript, database, or authentication is required.

## Main pages

- `index.html` — public BOAT Education Group website
- `login.html` — demo role selector
- `student-portal.html` — student dashboard
- `agent-dashboard.html` — agent overview
- `admin-dashboard.html` — super admin overview

All other portal pages are linked through their respective sidebars. Names, records, dates, amounts, and statuses are sample data for presentation purposes.
